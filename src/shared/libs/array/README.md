# Array Utilities

This directory contains utility functions related to array operations. These utilities are designed to help with common array manipulations and checks, making it easier to work with arrays in your applications.

## Contents

- `check-in-array.ts`: A function to check if a value exists in an array of objects based on a specific key.

## Array Utility Functions

In addition to the existing functions, this directory may also contain other useful array-related utility functions to assist with data manipulation and transformation.
