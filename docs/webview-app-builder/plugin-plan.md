# Отдельный WebView-плагин

Подтверждено пользователем 2026-09-30; создание начато после явного approval.

## Согласованная модель

- Отдельный пакет [MBANK WebView App Builder](../../plugins/mbank-webview-app-builder/README.md) хранит собственные docs и skills.
- React template будет отдельным GitHub-репозиторием. Сейчас репозиторий ещё не создан; его адрес и release tag/commit нужно задать после публикации.
- Пользователь может открыть пустую папку и запросить создание WebView-проекта: bootstrap получает выбранную версию template, устанавливает зависимости по lockfile и выполняет проверки.
- Skills остаются в установленном плагине и применяются к разным рабочим проектам.
- В существующем проекте сначала переиспользуются его компоненты и primitives. При необходимости агент читает выбранную версию GitHub-template и адаптирует нужный код вместе с зависимостями. Если подходящего UI нет, создаёт компонент по подтверждённым правилам.
- Создание UI не даёт права выдумывать API, backend endpoints или native capabilities.
- Для первой версии достаточно главного entrypoint, bootstrap и пяти специализированных skills. `agents/openai.yaml` — metadata для skills; отдельные Workspace Agents не требуются.

Документация пакета после начального переноса поддерживается как самостоятельный источник правил плагина. Эта база остаётся контекстом разработки React workbench; изменения правил для плагина выполняются в его docs в рамках соответствующей задачи.
